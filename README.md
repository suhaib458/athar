# ATHAR AI | أثَر

> **من النص إلى الأثر**

ATHAR AI هو نموذج أولي لذكاء تشريعي يحول التشريعات من نصوص متفرقة إلى شبكة علاقات قابلة للاستكشاف. يساعد فرق الصياغة والمراجعة على رؤية الأثر المحتمل لتعديل مادة واحدة على مواد وأنظمة وتعليمات وإجراءات مرتبطة.

صُنع هذا المشروع لمنافسة **هاكاثون التشريعات الذكية** الذي ينظمه مجلس الشباب الأردني.

## المشكلة

التعديل التشريعي لا يعيش بمعزل عن بقية المنظومة. قد تتأثر به تعريفات، مدد، إجراءات حذف، سجلات، أو التزامات إشعار لا تظهر عند قراءة المادة وحدها. هذا يجعل المراجعة أبطأ ويصعّب شرح أسباب التنبيه.

## الحل

يربط ATHAR كل نتيجة بدليلها داخل شبكة تشريعية، ثم يقدمها بصيغة واضحة:

- **ATHAR Engine — محرك التحليل:** قواعد حتمية قابلة للتفسير تعمل دون اتصال.
- **ATHAR Radar — كاشف التعارضات:** يرصد التعارضات المحتملة، المصطلحات غير المعرفة، الإحالات غير الصالحة، التكرار والاعتمادات.
- **ATHAR Ripple — الأثر المتسلسل:** خريطة تفاعلية توضح كيف ينتشر أثر التعديل بين طبقات المنظومة.
- **ATHAR Citizen — اشرحلي حقي:** واجهة مبسطة تشرح المعلومة التشريعية للمواطن بلغة مباشرة.
- **ATHAR Copilot — مساعد الصياغة:** نقطة انطلاق مهيأة لتدقيق مسودات المواد مستقبلًا.

## لماذا ATHAR مختلف؟

ليس ATHAR واجهة محادثة قانونية. المبدأ هو: **«نحن لا نطلب من الذكاء الاصطناعي أن يخمّن القانون؛ نحن نزوده بالبنية التشريعية أولًا، ثم نطلب منه تفسير الأدلة التي وجدها النظام.»**

في نسخة الهاكاثون، يعتمد النموذج على بيانات محلية وقواعد واضحة، لذلك يبقى Demo Mode متاحًا من دون قاعدة بيانات أو API أو إنترنت.

## سيناريو العرض

يحلل النموذج تعديلًا تجريبيًا على مادة الاحتفاظ بالبيانات الشخصية:

| النص الحالي | التعديل المقترح |
| --- | --- |
| تحتفظ الجهة بالبيانات الشخصية للمدة اللازمة لتحقيق الغرض من جمعها. | تحتفظ الجهة بالبيانات الشخصية لمدة خمس سنوات. |

يعرض الناتج أثرًا مرتفعًا، ست مواد متصلة، ثلاث طبقات تشريعية متأثرة، وتنبيهات قابلة للتفسير حول الحذف والمراجعة الدورية والسجل والإتلاف.

> جميع النصوص والمصادر في المشروع **بيانات تجريبية لأغراض النموذج الأولي** ولا تنسب إلى أي تشريع أردني رسمي.

## ATHAR Engine

المحرك الحالي deterministic ويغطي:

1. المصطلح غير المعرّف.
2. الإحالة التشريعية غير الصالحة.
3. التعارض المحتمل مع مادة مرتبطة.
4. الاعتمادات والمواد المستحقة للمراجعة.
5. التقارب أو التكرار المحتمل في صياغة أخرى.

يعتمد على abstraction باسم `AtharEngine` ويمكن توسيعه لاحقًا بمزودي Gemini أو OpenAI أو RAG دون إعادة بناء منطق المنتج.

## البنية

### Demo الحالي

```text
Demo Dataset → ATHAR Engine → Rules → Knowledge Graph → Cited Result
```

### المسار المستقبلي

```text
Official Legislation → Document Processing → Legislative Knowledge Graph
→ Vector Retrieval + Rules Engine → RAG / LLM → Cited Legislative Analysis
```

التوسع المقترح: PostgreSQL، pgvector، Neo4j، RAG، ونماذج Gemini/OpenAI كطبقة تفسير فقط.

## التقنية

- Next.js 16 + App Router
- React 19 + TypeScript strict
- Tailwind CSS 4
- Framer Motion (جاهز للاستخدام في امتدادات الحركة)
- React Flow (`@xyflow/react`) للخريطة التفاعلية
- Zod للتحقق من مدخلات التحليل
- Vitest لاختبارات محرك ATHAR

## خارطة الطريق

- استيراد مصادر تشريعية رسمية مع التوثيق والإصدار.
- بحث دلالي وRAG مرتبط بمصادر موثقة.
- ATHAR Copilot لفحص مسودات المواد.
- صلاحيات فرق العمل وسجل مراجعات.
- تصدير تقرير أثر تشريعي قابل للمشاركة.

## إخلاء مسؤولية قانونية

ATHAR AI أداة دعم قرار وتشريع؛ لا يصدر أحكامًا قانونية نهائية ولا يمثل استشارة قانونية ملزمة. تستلزم كل نتيجة مراجعة مختص قانوني ومصدر تشريعي رسمي قبل اعتمادها.
